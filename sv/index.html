Välkommen! Den här sidan har mest fungerat som ett digitalt visitkort så att folk kan hitta mig på andra platser på internet. Med tiden kan den innehålla bloggartiklar om min resa och mina intressen, som har förändrats och breddats genom åren.

Saker jag uppskattar:

  • Numera går det mesta av min fritid åt till yoga, löpning, mindfulness och vegansk mat.
  • Jag gillar fortfarande NixOS och fri mjukvara, även om jag inte är lika engagerad som förr – jag underhåller inte längre paket på samma sätt som tidigare.
  • Jag brukade ofta gå på konferenser som CCC och FOSDEM, vilket var ett bra sätt att träffa folk och lära sig nya saker.

Om du vill kontakta mig, se kontaktsektionen på om-sidan.
