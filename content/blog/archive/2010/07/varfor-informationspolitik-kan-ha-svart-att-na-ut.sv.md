Folk gillar inte abstrakta saker, är något som jag konstaterat genom åren. Jag tycker att det är ganska spännande.

När man kommer till saker som DRM eller något annat helt främmande för de flesta, så förstår de inte. Det är utom mångas möjlighet att förstå vad som menas med det. Och jag måste hålla med om att det inte är helt lätt för en icke-teckniker att se det absurda med DRM tex. Jag tror dock att man med rätt pedagogik kan förklara dessa saker så att i princip alla kan förstå vad man menar, och se det absurda i det. Jag har redan börjat med DRM, där jag jämförde med vatten på flaska. Vatten är något som de flesta ändå kan förstå. Så det jag gjorde med mitt flaskvatten var  typ att jag lade till absurda krav på hur du får använda/inte använda vattnet. Det är ändå ungefär så DRM fungerar.

Jag ser gärna att fler skriver sådana här saker och kommenterar här så jag kan lokalisera alla olika jämförelser av denna typ. Man kan använda dessa som inspirationskälla för att nå ut till fler nya personer genom att bryta ner ganska avancerade tekniska saker i något simplare *“mera vardagligt”* för de flesta.

Jag tror att genom att använda denna typ av pedagogik så kan vi nå ut på ett lättare sätt, med tekniska saker, på ett enkelt sett för icke-tekniker.
